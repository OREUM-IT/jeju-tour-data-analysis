## 변경 목적

제주 개인화 관광 Agent의 설계·데이터 조사·시각화·모델 검토 결과가 작업 환경에만 남아 있어 다른 Claude Code 세션이 이어받기 어려웠습니다. 전체 산출물을 버전 관리하고 `CLAUDE.md` → `docs/18-claude-code-handoff.md`에서 현재 상태, 재현 명령, 고정 참고 커밋, 다음 작업과 완료 기준을 읽을 수 있도록 정리했습니다.

## 포함 범위

- 18개 설계 문서: 문항→13축 프로필→8개 수작업 페르소나→후보 검색·제약·설명·일정 흐름, 데이터·평가·Vercel 통합 절차.
- 전체 AI AGENT MODEL 문서와 JSON: Gemini·OpenAI 기존 코드, Claude·Qwen3·Llama 후보, 미선정 임베딩·재정렬·군집 역할. 엔진·모델·방법·호스트·MCP를 분리하고 실제 실행 상태를 기록.
- 원본 CSV 55개에 대한 출처·해시·행·컬럼 인벤토리, 675개 컬럼 사전, 데이터 활용·정제 계획과 재생성 스크립트. 합계 210,532행은 고유 관광지 수가 아닙니다.
- 독립 페르소나 탐색 HTML, 설계도·시각화, 갱신한 Word/PDF 보고서, 인증 Ollama Gateway 예제 묶음.
- README·CLAUDE.md 인수인계, 문서·메타데이터·배포 산출물 검사를 CI에 추가. 원본 CSV ZIP·비밀 설정·로컬 카탈로그·의존성·캐시를 공개 Git에서 제외.

## 현재 범위와 미완료

기반 읽기 전용 MCP·HF 클라이언트·CI 코드는 이미 main에 반영되어 있습니다. 이번 PR은 전체 설계·데이터 메타데이터·산출물·인수인계를 추가합니다. 운영 Vercel 앱, DB, DNS, 참고 앱 저장소는 변경하지 않습니다.

논문 `2504.09277`의 본문·별도 PDF·원 Excel은 미확보이며 LAG를 RAG와 동일시하지 않습니다. 페르소나는 학습된 군집이 아닙니다. Ollama 추론·모델 비교·추천 품질·운영 통합은 미검증입니다. HF MCP 실제 연결은 작업 환경의 도메인 정책으로 차단되었고, HF 조직 생성·새 계정 인증도 완료하지 않았습니다. 공개 MCP 모의 검사 성공을 외부 연결 성공으로 해석하지 않습니다.

원본 CSV는 일부 재배포 조건이 미확정이므로 공개 PR에서 제외합니다. 카탈로그의 고정 원본 주소와 `--bundle` 옵션으로 로컬 재생성이 가능합니다. 모든 재현·접근 전제와 다음 작업 순서는 `docs/18-claude-code-handoff.md`에 기록했습니다. 검토 후 병합하는 변경이며 이 작업에서 자동 병합하지 않습니다.
