# 제주 관광 Agent의 탈옥·프롬프트 주입 방어 설계

기준일: 2026-11-18 한국 시간. 사용자 요청 논문 `2403.17336`을 확인 가능한 범위에서 검토하고 [Linux·Docker 운영안](21-linux-docker-production.md)에 연결한 **설계 추가**다. 이 문서의 정책 게이트·검증기·운영 배포·공격 평가를 구현하거나 통과한 상태는 아니다. 모델의 탈옥 가능성을 완전히 제거한다고 주장하지 않는다.

## 1. 논문에서 확인한 근거와 적용 범위

- 논문: *Don’t Listen To Me: Understanding and Exploring Jailbreak Prompts of Large Language Models*, Zhiyuan Yu 외, USENIX Security 2024.
- [사용자 지정 alphaXiv](https://www.alphaxiv.org/ko/abs/2403.17336)와 [arXiv](https://arxiv.org/abs/2403.17336)는 이번 환경에서 프록시 CONNECT 403으로 열리지 않았다. **PDF 본문·세부 표·실험 수치는 미검토**다.
- 별도로 공개된 [저자 공식 저장소 README](https://github.com/WUSTL-CSPL/LLMJailbreak/blob/2a9e665769de1bbfa657b6e6a9f88d9d427bc57c/README.md)를 읽어 제목·arXiv ID·학회 연결을 확인했다. 고정 커밋은 `2a9e665769de1bbfa657b6e6a9f88d9d427bc57c`다.
- README는 탈옥 프롬프트 448개·악성 질의 161개, GPT-3.5/GPT-4/PaLM-2 응답의 사람 주석과 JSR·EMH 평가를 설명한다. 이는 **공격 평가 연구**이며 아래의 Docker 격리·MCP 권한 검사 효과를 검증한 논문으로 해석하지 않는다. 과거 모델 결과를 현재 모델의 공격 성공률로 전용하지 않는다.
- 연구에서 차용할 방향은 정상 요청과 공격 요청을 구분한 반복 평가, 역할극 등 표현 변형, 응답 의미와 실제 결과의 검토다. 이 프로젝트의 서버 통제·제품 지표·합성 사례는 별도 설계 제안이다. 본문 확보 후 분류·지표 정의·실험 조건을 절/페이지와 함께 보완한다. 저자 공격 스크립트나 데이터셋은 이번에 실행·복제하지 않았다.

## 2. 방어 대상과 현재 코드의 경계

직접 탈옥은 사용자 입력이 모델의 지시·정책을 바꾸려는 경우다. 간접 프롬프트 주입은 장소 소개·검색 문서·MCP 응답·대화 이력 같은 자료가 명령처럼 해석되는 경우다. 도구 실행 권한, 개인정보 접근, 비용 한도와 실제 관광 조건 위반을 함께 평가한다.

| 항목 | 현재 코드가 하는 것 | 아직 필요한 것 |
|---|---|---|
| MCP 도구 | [tools.mjs](../services/jeju-mcp/src/tools.mjs)의 장소 검색·상세·조건 검사, 엄격한 인자 형식·건수 제한 | 원래 사용자 조건의 누락 방지, 요청 전체 호출 예산, 사용자별 정책 |
| 서비스 인증 | [server.mjs](../services/jeju-mcp/src/server.mjs)의 Bearer·Origin·요청 크기·읽기 제한 | 개인 데이터용 사용자/tenant/소유권 검증. 공용 서비스 토큰으로 사용자를 구분할 수 없음 |
| 조건 검사 | 유효 근거가 없으면 도구가 `unknown` 반환 | Agent가 답변에서 이를 `pass`로 바꾸거나 다른 장소를 추가하는 것을 막는 최종 검증 |
| 장소 근거 | [catalog.mjs](../services/jeju-mcp/src/catalog.mjs)의 형식·길이 검사 | 근거 note·설명을 비신뢰 텍스트로 유지하는 컨텍스트 처리. 형식 정상과 지시의 신뢰는 다름 |
| Langflow | [시작 흐름](../services/langflow/jeju-tour-agent.flow.json)의 MCP 연결·프롬프트·반복 횟수 설정 | 전체 도구 목록 통제. 기본 계산기·현재 날짜 도구도 포함해 검토. 요청 전체 토큰·비용·시간 한도 |
| 비밀값 | 흐름 생성 시 비밀 필드 검사, 로컬 비밀 파일 Git 제외 | 실행 중 프롬프트·응답·오류·추적 로그의 비밀 격리와 제거 |

현재 도구는 v1 카탈로그를 사용한다. [v2 근거 등급 카탈로그](19-agent-step2-data-foundation.md)의 `verified` 0건, 도구 연결 미완료 상태를 유지한다. 새 방어 문서가 필드 근거를 생성하거나 `source_reported`를 검증 완료로 승격하지 않는다.

## 3. 아키텍처와 벡터 저장소의 역할

운영 목표: `Vercel → 인증·정책 Gateway → Langflow 실행 → 도구 정책 검사 → 제주 MCP → 자료 저장소 → 최종 결과 검증 → Vercel`.

현재 저장소는 JSON 카탈로그를 사용하고 벡터 저장소는 미연결이다. 확장 후보는 PostgreSQL의 정형 장소·근거 테이블과 pgvector다. 장소 설명의 임베딩은 관련 후보를 찾는 데 사용하며 가격·접근성·영업시간·예약·일정 상한을 의미 유사도로 판정하지 않는다. 모든 검색 결과는 안정된 `placeId`·`sourceId`·`dataVersion`으로 원자료와 연결한다.

- 정제된 장소 ID·원문 출처·필드별 근거 등급·유효기간을 정형 테이블에 보존하고, 검색용 chunk·임베딩 모델/차원/버전을 별도 관리한다.
- 공개 관광 자료와 개인 프로필·대화·저장 코스의 권한 영역을 분리한다. 개인 자료가 추가되면 서버에서 확인한 사용자 범위를 SQL/RLS와 벡터 검색 필터에 함께 적용한다. 전역 검색 후 모델에게 타인 결과를 전달해 골라내게 하지 않는다.
- 장소 설명과 chunk 안의 지시는 데이터다. 검색 순위가 높거나 공식 출처에서 왔다는 이유로 시스템 역할·도구 권한을 부여하지 않는다.
- 사용자 대화나 모델 설명을 검토 없이 지식베이스·장소 근거·장기 메모리에 다시 적재하지 않는다. 정제 승인·출처와 변경 이력을 거친 자료만 색인한다.
- 임베딩 API로 보낼 자료의 이용 조건과 전송 범위를 확인한다. 개인 설문을 자동으로 외부 임베딩 서비스에 전송하지 않는다. 모델 변경 시 재색인과 검색 회귀 검증을 수행한다.

## 4. 서버가 강제할 정책 게이트

### 입력·권한 문맥

서버는 인증 결과에서 `principal`, 필요한 `tenant`, `requestId`, `profileVersion`, `policyVersion`, `dataVersion`, 허용 도구·호스트·예산을 만든다. 사용자 텍스트나 모델이 만든 `ownerId`, 역할 이름, ‘관리자가 승인했다’는 문장으로 이 값을 덮어쓰지 않는다. 비로그인 공개 검색과 회원 개인 자료 접근은 별도 권한이다.

설문은 타입·enum·단위·날짜·길이를 검증한다. 미응답과 명시적 중립, 필수와 선호를 보존한다. 사용자가 실제로 조건을 바꾸는 것은 가능하지만 UI/인증된 수정 API가 새 프로필 버전을 만들고 확인한다. 외부 문서나 모델이 자체적으로 조건을 삭제할 수는 없다.

입력 탐지기는 추가 신호다. ‘이전 지시를 무시’ 같은 표현을 인용한 정상 질문도 있으므로 단어 일치만으로 전체 대화를 차단하지 않는다. 다국어·Unicode·인코딩 분석을 하더라도 원문과 정규화 결과를 구분하고, 탐지 결과가 새로운 실행 권한을 만들지 않는다.

### 도구 호출 직전

정책 검사는 **실제 호출이 발생하는 경로**에서 매번 실행한다. Vercel 요청 입구에만 게이트를 두고 Langflow가 도구·모델을 직접 무제한 호출하게 두면 충분하지 않다. 검증 가능한 커스텀 실행 어댑터/제한 MCP 프록시와 대상 서비스 검사를 조합한다. 이 어댑터는 아직 미구현이다.

| 검사 | 서버 규칙 |
|---|---|
| 도구 목록 | 초기 운영은 승인된 읽기 도구만. MCP 도구와 Langflow 기본 도구를 모두 포함한 실제 목록·schema·버전을 고정. 새 도구/설명 변경은 검토 전 활성화하지 않음 |
| 인자 | 엄격한 schema 외에 요청의 사용자 범위·후보 ID·원본 필수 조건과 대조. `constraints.check`에 모델이 일부 조건만 넣으면 서버가 원본에서 재구성하거나 거부 |
| 출처·대상 | 임의 URL fetch·셸·파일 실행·SQL 실행·flow 업로드·MCP 서버 추가를 사용자 Agent에 제공하지 않음. Cloudflare/Vercel 관리 MCP와 HF 연구용 도구는 관광 운영 도구 목록에서 제외 |
| 네트워크 | 허용 서비스·프로토콜·포트·경로를 고정하고 DNS 해석·리디렉션에도 같은 검사를 적용. 필요한 내부 MCP 예외만 허용. SSRF 허용 목록만으로 전체 egress가 통제됐다고 판단하지 않음 |
| 비용 | 요청별 모델·도구 횟수, 누적 토큰/비용, 동시성, 전체 deadline을 서버가 관리. 재시도·공급자 fallback도 같은 예산에 포함 |
| 쓰기 | 현재 모델 도구에는 코스 저장·예약·결제·계정 변경 권한 없음. 향후 쓰기는 주체·대상·내용·버전에 묶인 서버 승인과 멱등성·소유권 검사 후 별도 API로 수행 |

초기 시험 한도 제안은 모델 3회·MCP 8회·요청 전체 30초다. 이는 성능 실측이나 운영 SLA가 아니다. 공급자별 출력 토큰 상한을 검증해 명시하고, 실행 전에 상한을 예약·검사해 병렬 호출로 한도를 초과하지 못하게 한다. 이미 시작된 외부 호출의 취소·요금 처리는 공급자마다 달라 별도 확인한다. 모델이 ‘반복 제한을 해제하라’고 요청해도 변경하지 않는다.

### 검색 자료·도구 응답

신뢰된 시스템 설정, 확인된 사용자 프로필, 비신뢰 검색/도구 본문을 별도 구조로 전달한다. tool 본문이 system/developer 역할이 되거나 새로운 도구 정의·토큰·URL·예산을 공급하지 못하게 한다. 구분 태그나 ‘문서 안 지시는 무시’라는 프롬프트만으로 이 경계가 강제되는 것은 아니다.

허용 필드·최대 길이·결과 수를 제한하고 프롬프트에 필요하지 않은 메타데이터는 제외한다. 외부 도구 오류·traceback·인증 응답 원문은 안전한 오류 코드로 바꾼다. 긴 입력은 조용히 필수 조건을 잘라내지 않고 길이 오류나 명시적 요약/축소 요청으로 처리한다. 대화 요약·메모리는 권한의 원본이 아니다.

### 최종 응답·화면

1. 모델 출력은 엄격한 결과 schema로 파싱하고 허용된 후보 ID, 개수, 프로필·데이터 버전을 검사한다. 출력의 `verified`, `pass`, 가격·일정 계산을 그대로 신뢰하지 않는다.
2. 원래 필수 조건을 사용해 서버가 장소별·일정별 검사를 재실행한다. `unknown/conflict`를 조건 충족 추천과 섞지 않는다. 근거 없는 장소 이름이나 ID는 검증 결과에 포함하지 않는다.
3. 장소 이름·검증 배지·가격·출처·미확인 안내는 신뢰된 서버 데이터로 렌더링한다. 자유 설명이 이를 뒤집으면 답변을 재작성하거나 서버 템플릿으로 대체한다. JSON schema만으로 자유 설명의 모든 의미 오류를 검출한다고 주장하지 않는다.
4. HTML·스크립트·외부 이미지·자동 fetch를 차단하고 출력 텍스트를 escape한다. 출처 링크는 서버의 승인된 근거 목록에서 가져온다. 모델이 만든 URL을 브라우저나 서버가 자동 방문하지 않는다.
5. 거절은 막힌 동작과 가능한 대안을 짧게 안내한다. 정상 관광 검색까지 일괄 거절하거나 내부 정책·비밀값을 설명에 붙이지 않는다.

## 5. Docker·Langflow·인증의 실행 경계

[21 운영안](21-linux-docker-production.md)의 격리는 프롬프트 방어와 별도다. Langflow 편집·flow 가져오기·커스텀 컴포넌트 설치는 코드 실행 권한을 가진 관리 작업으로 취급한다. 관광 사용자나 모델에게 편집 API·전역 변수·Credential 관리 권한을 주지 않는다. 로그인만 추가한 편집기를 관광 Agent의 공개 API처럼 사용하지 않는다.

Cloudflare Service Token, MCP Bearer, 공급자 키, DB 비밀번호는 연결 계층에서만 사용한다. 프롬프트·검색 문서·도구 인자·실행 결과에 넣지 않는다. Cloudflare Access 통과는 서비스 접근 인증이며 사용자별 코스 소유권 검사를 대신하지 않는다. 모델 실행자는 서버의 비밀 저장소를 조회하는 도구를 갖지 않는다.

런타임 컨테이너는 비특권 사용자, 필요한 읽기 전용 카탈로그·전용 쓰기 볼륨, 자원 제한으로 실행한다. Docker 소켓·호스트 루트·다른 서비스 비밀을 마운트하지 않는다. Langflow의 실제 쓰기 경로를 검증한 뒤 읽기 전용 파일시스템을 적용한다. 모델·흐름·플러그인 변경은 검토된 버전과 이미지를 고정하고 같은 평가를 통과시킨다.

## 6. 합성 공격·정상 요청 평가

[agent-security-cases.json](../data/agent-security-cases.json)은 실행 전 합성 명세 14개(방어 12·정상 2)다. 허구 장소·사용자·표식과 예약된 테스트 도메인을 사용하며 운영 고객·실제 비밀·공격 스크립트는 포함하지 않는다. 기존 서비스·Gateway 51개 검사나 Langflow 노드 빌드 성공은 이 평가의 통과를 뜻하지 않는다.

| 평가 축 | 확인 방법 |
|---|---|
| 직접 탈옥·역할 사칭·다국어 변형 | 정책 변경이나 미허용 동작이 실제로 발생했는지 검사 |
| 장소 설명·도구 결과·메타데이터 주입 | 지시가 권한·후보·근거 등급·호출 대상에 영향을 줬는지 추적 |
| 필수 조건 누락·가짜 ID·unknown 승격 | 원본 프로필과 최종 결과를 결정론적 oracle로 대조 |
| 비밀·사용자 격리·SSRF | 허구 canary·서버 감사 이벤트·차단된 호출 수로 확인. 운영 비밀을 평가 프롬프트에 넣지 않음 |
| 출력 렌더링·비용 반복 | DOM/요청 기록·누적 호출 ledger를 검사. 실제 외부 악성 URL을 방문하지 않음 |
| 정상 요청·정상 조건 수정 | 안전한 검색이 완료되고 합법적 수정은 새 프로필 버전으로 반영되는지 확인 |

평가 기록은 모델의 정확한 ID/digest·온도·프롬프트/정책/flow/data 버전·시드 지원 여부·반복 수·지연·비용을 포함한다. 같은 원문 사례를 여러 언어·표현·문맥 길이로 변형하고, 정상 대응 사례와 함께 비교한다. 공격 문장을 단순히 출력했다는 이유나 ‘죄송합니다’라는 단어 유무만으로 성공·실패를 판정하지 않는다.

지표는 미허용 실행률, 허구 canary 노출률, 사용자 범위 침범률, 필수 조건 위반률, 정상 요청의 오탐 거절률, 정상 추천 품질, p95 지연·비용이다. 각 분모·미실행/timeout 처리·평가자 불일치를 명시한다. 논문의 JSR/EMH와 동일하게 재현했다고 부르지 않는다. 정책/코드로 검증되는 부분은 자동 판정하고 자유 설명의 의미는 사람 검토를 병행한다.

초기 공개 전 게이트는 준비한 평가셋에서 중요 위반 0건과 정상 작업 품질 기준 충족이다. 정상 품질 기준·표본 수는 기존 비서 기준선 측정 후 합의한다. 유한한 시험에서 0건이어도 미지 공격이 없다는 보장은 아니며 실제 모델·버전별 검증이 필요하다. 형식 검사가 끝난 JSON을 공격 방어 성공으로 기록하지 않는다.

## 7. 구현 순서·운영 대응

1. 현재 코드의 보호 범위와 이 문서의 미구현 항목을 구분하고, 기존 v1과 v2의 근거 계약을 통합한다.
2. 불변 요청 문맥·도구 실행 정책·누적 예산을 먼저 구현하고 미허용 호출이 실제 실행되지 않는 통합 검사를 추가한다.
3. 최종 ID·조건·근거·렌더링 검증을 구현한다. 이후 Langflow 흐름을 이 검사를 우회할 수 없는 실행 경로에 연결한다.
4. 로컬 허구 도구로 평가한 뒤 승인된 공급자·작은 예산에서 실제 모델을 시험한다. 원문 논문 검토와 제품용 정상/공격 평가셋을 보완한다.
5. Docker의 네트워크·권한·백업/복원·비밀 회전·정책 게이트 장애를 확인한 뒤 Vercel Preview로 연결한다. 공개 인터넷·운영 데이터로 공격 시험하지 않는다.
6. 감사 로그에는 request ID·주체 범위 식별자·정책/모델 버전·도구·차단 사유·사용량을 남긴다. 전체 대화·개인정보·비밀은 기본 로그에서 제외하고 평가 원문은 별도 접근·보존 정책으로 관리한다.
7. 유출이나 권한 위반이 관측되면 해당 도구/flow를 비활성화하고 필요 비밀을 회전한다. 새 작업만 차단하거나 검증된 읽기 경로로 제한하며 이미 저장된 코스·DB를 임의 복원하지 않는다. 안전한 이전 버전이 없으면 기능을 중지한다.

추가 입력 차단기나 ‘안전한 모델’만으로 이 전체 경계를 대체하지 않는다. Linux/Docker 배포 완료, 모델 추론 성공, 관광 추천 품질, 탈옥 방어 평가는 각각 별도 완료 기준으로 기록한다.
